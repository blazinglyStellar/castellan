# Security Policy

## Reporting a Vulnerability

Castellan handles financial transactions on the Stellar network. Security is a top priority.

If you discover a security vulnerability, please **do not** open a public issue. Email the maintainer at the address listed in the commit history or open a draft GitHub Security Advisory.

### What to include

- Type of issue (XSS, SQL injection, cryptographic flaw, etc.)
- Steps to reproduce
- Affected versions
- Any proof of concept or exploit code

### Response timeline

- **48 hours:** Acknowledgment of receipt
- **7 days:** Initial assessment and mitigation plan
- **30 days:** Fix deployed (depending on severity)

## Responsible Disclosure

We follow coordinated disclosure. Please allow reasonable time for a fix before disclosing the issue publicly.
